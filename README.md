## 🧠 Data Structures & Algorithms Used

- **Data Structures:** Linked List, Pointers, OOPs Concepts
- **Algorithms:** Bubble Sort, Linked List Traversal, Linear Search

---

## 📌 Features

- **Record Creation & Management:** Easily add new students, update existing profiles, and remove records.
- **Dynamic Search & Filtering:** Quickly locate student profiles using Roll Number, Name, or Course.
- **Academic Performance Tracking:** Monitor grades, semester-wise marks, attendance, and overall performance.
- **Client-Side Data Persistence:** Structured local management to ensure records persist across reloads.
- **Clean & Responsive UI:** Fully responsive layout built to adapt smoothly across mobile and desktop.
- **Input Validation:** Built-in checks to prevent duplicate entries and invalid data formats.

## 🛠️ Tech Stack

- **Core / DSA Logic:** C++ (OOPs, Pointers, Linked Lists)
- **Frontend / Web UI:** HTML5, CSS3, JavaScript (ES6+)
- **Deployment:** GitHub Pages
